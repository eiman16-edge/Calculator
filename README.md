# Calculator

A simple calculator project built with HTML, CSS, and JavaScript. It lets you enter numbers and basic arithmetic operations using on-screen buttons.

## Features

- Addition, subtraction, multiplication, and division
- Clear button to reset the display
- Centered, responsive layout

## Project files

- `index.html` — calculator structure
- `style.css` — layout and styling
- `script.js` — calculator behavior
  
Live demo : https://eiman16-edge.github.io/Calculator/
